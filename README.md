# Haven Health

Build a complete, modern, premium, professional, calm, and minimalistic hospital website.

The website should feel like a high-end modern private hospital combined with the clean UX of a modern healthcare technology platform.

The overall experience should communicate:

Trust + Compassion + Safety + Professionalism + Modern Healthcare + Simplicity

Do not make it look like a generic hospital template. Create a polished, distinctive, modern website with excellent spacing, typography, responsive design, and user experience.

1. BRAND & VISUAL IDENTITY

Color Palette

Use a clean light blue and white color system.

Primary colors:

White — main background

Very light blue — section backgrounds

Soft/light blue — secondary backgrounds

Medium blue — primary brand/accent color

Dark navy blue — headings and important text

Cool gray — secondary text

Very light gray/blue — borders and dividers

Suggested direction:

Primary Blue: #2F80ED

Light Blue: #EAF4FF

Very Light Blue: #F7FBFF

Navy: #12304A

Text Gray: #64748B

White: #FFFFFF

These are design references; maintain visual harmony rather than forcing every component to use all colors.

Use blue carefully. The website should remain predominantly white and spacious.

Design Style

The website should have:

Large amounts of whitespace

Clean layouts

Rounded cards

Soft shadows

Thin subtle borders

Large readable headings

Professional photography

Simple medical icons

Soft blue backgrounds

Rounded buttons

Clean forms

Subtle gradients

Minimal visual noise

Smooth transitions

Modern UI components

Avoid:

Dark overall themes

Excessive gradients

Neon colors

Excessive shadows

Huge amounts of text

Cluttered layouts

Overly complicated animations

Generic stock-template appearance

Excessive glassmorphism

Excessively rounded "bubble" interfaces

The final website should feel calm, trustworthy, premium, and human.

2. TYPOGRAPHY — IMPORTANT

Use Poppins as the primary font family throughout the entire website.

Import Poppins from Google Fonts and apply it globally.

Use these weights appropriately:

300 — Light

400 — Regular

500 — Medium

600 — Semi Bold

700 — Bold

Typography hierarchy:

Hero headings

Poppins 600–700

Section headings

Poppins 600

Card headings

Poppins 500–600

Body text

Poppins 400

Navigation

Poppins 500

Buttons

Poppins 500–600

Labels and captions

Poppins 400–500

Make the typography spacious, clean, modern, and highly readable.

Do not randomly introduce other font families.

The combination of:

Poppins + light blue + white + whitespace + rounded UI + clean photography

should form the core visual identity.
